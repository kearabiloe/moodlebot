Getting started

How to Install

Follow these three steps to install the MoodleBot Chrome extension:

Download and Open Chrome

Click Download Now to download the MoodleBot.crx extension file. Open your Google Chrome browser on your computer.

Enable Developer Mode

Navigate to chrome://extensions. In the top-right corner, toggle the Developer mode switch to the right to enable it.

Install the Extension

Drag and drop the downloaded MoodleBot.crx file into the Chrome Extensions page. Confirm the installation.
